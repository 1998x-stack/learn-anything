## 一、五大学习法一览

| 方法 | 创始人 | 来源 | 核心理念 | 最适用场景 |
|------|--------|------|---------|-----------|
| **费曼学习法** | 理查德·费曼 | 1988年（整理） | 以教促学，输出倒逼输入 | 理解型/原理型知识 |
| **西蒙学习法** | 赫伯特·西蒙 | 认知心理学研究 | 目标聚焦，持续专注，6个月精通 | 系统性技能学习 |
| **SQ3R阅读法** | 弗朗西斯·罗宾逊 | 1946年《有效学习》 | 主动阅读，结构化处理文本 | 教材/学术书籍精读 |
| **番茄学习法** | 弗朗西斯科·西里洛 | 1988年 | 时间分块，战胜拖延 | 长时间学习的专注管理 |
| **康奈尔笔记法** | 沃尔特·波克 | 1940年代 | 记学思用一体化笔记系统 | 课堂听讲/复习备考 |

## 三、使用场景决策树

```
遇到学习任务，如何选择方法？

你的任务是：

  读一本书/一篇论文？
  │   → 用 SQ3R 阅读法
  
  记课堂笔记或整理学习内容？
  │   → 用 康奈尔笔记法
  
  验证自己是否真的理解了某个概念？
  │   → 用 费曼学习法
  
  想在6个月内系统掌握一个新领域？
  │   → 用 西蒙学习法（制定整体计划）
  
  容易分心、拖延、难以开始？
  │   → 用 番茄工作法
  
以上都适用？
  → 用"组合套餐"（见下节）
```

## 四、黄金组合套餐

### 套餐A：日常课程学习（适合在校学生）

```
  课前预习（20分钟）：
    → SQ3R的Survey+Question阶段
    
  课中记录（45-90分钟）：
    → 康奈尔笔记法的Record阶段
    → 番茄法辅助专注（可设2个番茄）
    
  课后（当天内，30-40分钟）：
    → 康奈尔法的Reduce + Recite + Reflect
    → 费曼法验证：能否用白话讲清楚关键概念？
    
  每周复习（30分钟）：
    → 康奈尔法的Review
    → SQ3R的Review
```

### 套餐B：备考冲刺（适合考证/升学备考）

```
  阶段1：教材精读（第1-2周）
    → 西蒙法：制定模块化学习计划
    → SQ3R：系统阅读每一章
    → 番茄法：每天8-12个番茄
    
  阶段2：知识内化（第3-4周）
    → 康奈尔笔记：整理复习笔记
    → 费曼法：对每个重点章节尝试讲解
    → 番茄法：保持每日高强度专注
    
  阶段3：查漏补缺（考前1周）
    → 康奈尔法Review：看提示栏自测
    → 费曼法：重点攻克仍讲不清楚的概念
    → 番茄法：短冲刺+充分休息
```

### 套餐C：自学新技术（适合IT从业者/职业人士）

```
  月度计划：
    → 西蒙法：明确6个月目标，拆解模块
    
  每日执行：
    → 番茄法：管理每天学习时间
    → SQ3R：阅读技术文档/书籍
    → 康奈尔：记录技术笔记（提示栏=API/命令）
    
  每周验证：
    → 费曼法：能否向没学过的人解释本周核心概念？
    → 动手实践项目（费曼法的"应用验证"）
```
