# 🎨 HTML 可视化生成指南

> 本文件定义如何使用 `frontend-design` 技能将学习内容生成为精美的 HTML 页面。

---

## 一、调用方式

```
使用 Skill("frontend-design") 工具，传入以下上下文：
- Purpose: 该页面要传达什么
- Style direction: 美学方向
- Constraints: 技术约束
- Differentiation: 记忆点
```

**重要**：在调用前，先向用户简明说明设计概要（目的、风格、约束、差异化），获得认可后再调用技能。

---

## 二、四要素模板

### 2.1 Purpose（目的）

从源内容提炼 1-2 句话，表达该页面要传达什么：

- "一份交互式对比图，展示五种学习法在认知深度、时间投入和最佳场景上的差异"
- "一份费曼学习法的个人实践笔记，记录用费曼法解释JS闭包的完整过程"
- "一份 SQ3R 阅读法操作指南，带分步骤的交互式演示"

### 2.2 Style Direction（风格方向）

根据学习法选择对应的美学方向：

| 学习法 | 推荐风格 | 配色参考 | 排版感觉 |
|--------|---------|---------|---------|
| 费曼学习法 | playful / toy-like | 暖橙 + 奶油白 | 圆润友好，手写感 |
| 西蒙学习法 | industrial / utilitarian | 钢蓝 + 石板灰 | 干练精准，几何感 |
| SQ3R 阅读法 | editorial / magazine | 报纸米白 + 深红 | 排版层级分明 |
| 番茄学习法 | brutalist / minimal | 番茄红 + 纯白 | 极简克制，功能至上 |
| 康奈尔笔记法 | refined / minimal | 海军蓝 + 羊皮纸 | 经典学术，精致克制 |
| 综合对比 | magazine / art-deco | 深棕 + 金 | 信息密度大，结构清晰 |
| 个人学习笔记 | organic / natural | 大地色系 | 温暖手作，松弛感 |

### 2.3 Constraints（约束）

使用以下标准约束（可根据场景调整）：

- 单文件自包含 HTML（无外部依赖）
- 响应式布局（desktop + mobile）
- 嵌入 CSS/JS（`<style>` + `<script>` 标签）
- 不做打印版本适配
- 不使用 Google Fonts 或 CDN 外部资源
- 面向学习场景，信息可读性优先

### 2.4 Differentiation（差异化记忆点）

每页一个独特的视觉钩子：

- 费曼法页面：悬浮的"教具卡片"，hover 时翻转显示解释
- 对比页面：中央径向图，hover 方法名展开详细描述
- 康奈尔笔记页面：真实的三栏笔记布局，渐变分隔线模拟纸张
- 番茄法页面：倒计时环动画，番茄图标作为进度指示器

## 三、前置准备流程

在调用 `Skill("frontend-design")` 之前：

1. **读取源内容**：从 `raw/` 文件、对话上下文或 wiki 笔记中获取
2. **摘要提炼**：将长内容压缩为 3-5 个要点（前端设计技能不需要完整原文）
3. **选择方向**：根据上表选择风格和配色
4. **组装 Prompt**：将四要素 + 摘要内容组合为一句完整的用户请求
5. **调用技能**：`Skill("frontend-design")`

### Prompt 组装示例

```
创建一个学习法可视化页面：
- 目的：对比5种学习法的认知深度、时间投入和最佳场景
- 风格：杂志编辑风，报纸米白底色 + 深红强调色
- 约束：单文件HTML，响应式，无外部依赖
- 差异化：中央径向对比图，hover时展开方法详情

内容摘要：
- 费曼法：以教促学，90%记忆保留率，适合理解型知识
- 西蒙法：6个月精通，聚焦专注，适合系统性技能
- SQ3R：5步主动阅读，Survey→Question→Read→Recite→Review
- 番茄法：25分钟专注单元，战胜拖延，适合执行管理
- 康奈尔法：5R一体化笔记，Record→Reduce→Recite→Reflect→Review
```

---

## 四、输出接收与验证

1. **捕获输出**：前端设计技能返回 HTML/CSS/JS 内容
2. **写入文件**：保存至 `visualize/<descriptive-name>.html`
3. **验证**：
   - 文件以 `<!DOCTYPE html>` 或 `<html` 开头
   - 包含 `<style>` 标签（自包含 CSS）
   - 文件大小合理（不超过 500KB）
   - 在 `visualize/` 目录下
4. **向用户报告**：告知文件路径和设计概要

## 五、常见场景速查

| 用户请求 | 页面类型 | 推荐风格 |
|---------|---------|---------|
| "帮我做个对比图" | 方法对比仪表盘 | editorial / magazine |
| "把这个笔记做成网页" | 学习笔记展示页 | organic / natural |
| "画一个XX法的学习路径" | 步骤/阶段流程图 | refined / minimal |
| "这个聊天总结成页面" | 对话精华摘要页 | brutalist / minimal |
| "显示五种方法的关系" | 关系图谱/概念图 | art-deco / geometric |
