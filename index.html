Learn Anything

A personal learning system that transforms raw notes into structured knowledge — guided by the five most proven learning methods, powered by Claude Code.

claude-code-skill
Method 1

Feynman Technique

"If you can't explain it simply, you don't understand it."

Choose topic → Teach a child → Identify gaps → Simplify & analogize

Method 2

Simon Method

6 months to mastery through focused, deliberate practice.

Set target → Decompose into modules → Deep focus → Feedback → Integrate

Method 3

SQ3R Reading

Active reading that makes every page count.

Survey (10%) → Question (10%) → Read (50%) → Recite (20%) → Review (10%)

Method 4

Pomodoro Technique

25 minutes of focused work — beat procrastination, build momentum.

Plan task → 25min focus → 5min break → Repeat 4× → 15–30min long break

Method 5

Cornell Notes (5R)

One notebook system for capture, comprehension, and review.

Record → Reduce → Recite → Reflect → Review
